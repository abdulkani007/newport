## 🔧 TECHNICAL DETAILS

### CSS Units Used
- **rem** - Relative to root font size (scalable)
- **em** - Relative to parent font size
- **%** - Percentage of parent
- **vw/vh** - Viewport width/height
- **Minimal px** - Only for borders and shadows

### Flexbox Usage
```css
- Navigation menu
- Button groups
- Social links
- Card content
- Footer layout
```

### CSS Grid Usage
```css
- Home container
- Project grid
- Certificate grid
- Achievement grid
- Coding profiles grid
```

### Media Query Strategy
```css
1. Base styles (desktop-first)
2. @media (max-width: 1024px) - Tablet
3. @media (max-width: 767px) - Large phones
4. @media (max-width: 480px) - Mobile
5. @media (max-width: 360px) - Extra small
```
